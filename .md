# MASTER PROMPT — GRENVIS SMART PLANT MONITORING SYSTEM

Saya sedang mengembangkan GRENVIS (Green Vision Intelligent System),
sebuah robot Smart Plant Monitoring berbasis:

- ESP32 utama
- ESP32-CAM AI Thinker
- Computer Vision
- Machine Learning sensor
- ESP-NOW
- MQTT
- EMQX Cloud
- Website Dashboard

Tujuan sistem adalah memantau kondisi tanaman berdasarkan:

1. Kondisi visual daun
2. Suhu lingkungan
3. Kelembapan udara
4. Kelembapan tanah
5. Risiko lingkungan
6. Kebutuhan penyiraman
7. Perubahan kondisi berdasarkan waktu

Sistem TIDAK boleh menganggap output AI sebagai diagnosis penyakit yang pasti.
Gunakan istilah seperti:

- Possible indication
- Visual indication
- Environmental risk
- AI detected pattern
- Recommended inspection

============================================================

- MAC Address
- IP Address

- MQTT Status


Contoh:

ESP32-CAM juga harus menampilkan MAC Address saat boot.


Sediakan konfigurasi:

uint8_t mainEsp32Mac[] = {
    0x00, 0x00, 0x00,
    0x00, 0x00, 0x00
};


Jelaskan cara mengubah:

AA:BB:CC:11:22:33

menjadi:

{
  0xAA, 0xBB, 0xCC,
  0x11, 0x22, 0x33
}

8. WIFI CHANNEL DAN ESP-NOW
============================================================

ESP32 utama terhubung ke WiFi untuk MQTT.

WiFi.channel()

ESP32-CAM harus menggunakan channel yang sama.

Jangan menggunakan channel berbeda.

Jika channel berbeda, berikan pesan/error yang mudah dipahami.


============================================================
9. ESP-NOW RECEIVER CALLBACK
============================================================

Gunakan callback yang kompatibel dengan ESP32 Arduino Core terbaru:

void onEspNowReceive(
    const esp_now_recv_info_t *info,
    const uint8_t *incomingData,
    int len
)


Callback hanya boleh:

- validasi ukuran
- memcpy data
- mengambil sender MAC
- menyimpan hasil vision
- menyimpan timestamp millis()
- mengubah flag newData
- mencetak informasi ringan jika diperlukan

JANGAN:

- melakukan MQTT publish berat
- menjalankan inference
- menjalankan proses blocking panjang

di dalam callback.

50. STATUS IMPLEMENTASI DAN FITUR YANG BELUM AKTIF
============================================================

Status diperiksa pada 4 September 2026.

SUDAH AKTIF PADA DASHBOARD:

- Ringkasan 24 jam dan analisis tren sederhana
- Mode demo untuk menjalankan dashboard tanpa perangkat

BELUM AKTIF / BELUM SELESAI:

1. AI Vision asli pada ESP32-CAM belum dipasang. Sketch yang tersedia masih test sender dengan probabilitas simulasi Healthy 10%, Powdery 20%, dan Rust 70%.
2. Pengambilan, pengiriman, dan penyimpanan foto daun belum aktif. Area latest capture di dashboard masih menunggu `image_url` atau `image_path` dari backend.
3. Soil moisture sensor fisik belum dibaca. Firmware ESP32 Main masih menghasilkan nilai kelembapan tanah simulasi.
4. Model `grenvis_sensor_model.h` belum tersedia di folder project dan harus disalin secara lokal sebelum firmware ESP32 Main dapat dikompilasi.
5. Compile, upload, dan pengujian end-to-end pada ESP32/ESP32-CAM asli belum dilakukan dari environment ini.
6. Database production belum tersedia. History dan watering event saat ini hanya disimpan sebagai JSON lokal dan tidak ikut diunggah ke Git.
7. Alert eksternal seperti email, WhatsApp, Telegram, SMS, atau push notification belum aktif. Priority/alert saat ini hanya tampil sebagai informasi pada dashboard.
8. Penyiraman otomatis dengan relay, pompa, atau valve belum aktif. Sistem hanya memberikan rekomendasi dan mencatat tombol "I watered this plant".
9. Perbandingan soil moisture sebelum dan sesudah penyiraman belum lengkap karena event baru menyimpan nilai `soil_before`.
10. Login, autentikasi pengguna, pembagian role, dan manajemen akun belum tersedia.
11. Export laporan harian ke PDF/CSV dan penjadwalan laporan belum tersedia.
12. Deployment production, domain, HTTPS aplikasi, monitoring server, dan backup database belum disiapkan.
13. Validasi TLS MQTT dengan CA certificate pada firmware belum aktif; `setInsecure()` masih digunakan untuk prototype.
14. Threshold sensor masih nilai awal dan belum dikalibrasi untuk spesies tanaman, media tanam, dan sensor fisik yang digunakan.

CATATAN KEAMANAN:

- Kredensial WiFi dan MQTT disimpan hanya pada file lokal `config.h` dan `.env` yang diabaikan Git.
- File `config.example.h` dan `.env.example` hanya berisi placeholder dan aman dijadikan template.
